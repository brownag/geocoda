# Development Archive

This directory contains historical development documentation, implementation plans, and architectural notes from the geocoda project development.

## Contents

### `/scratch`

Early-stage implementation planning and research notes:
- `PHASE_*_IMPLEMENTATION_PLAN.md` - Phase-based development roadmaps (historical reference)
- `MINING_GEOSTATISTICS_LITERATURE_REVIEW.md` - Literature research and technical background
- `RUNNING_EXAMPLES.md` - Instructions for running code examples with environment variables
- `09_feature_roadmap.Rmd` - Feature and capability status documentation (archived from vignettes)

## `/github-dev`

Internal GitHub development and completion records:
- `FINAL_COMPLETION.md` - Phase completion summaries
- `IMPLEMENTATION_DETAILS.md` - Technical implementation notes
- `PHASE2_SUMMARY.md` - Multi-backend hierarchical models development log
- `VIGNETTE_DECISION.md` - Documentation structure decisions
- Status reports and refinement summaries

## Usage

These files are provided for historical context and reference. They document:
- Architectural decisions made during development
- Feature implementation timelines and phases
- Research foundations for key methodologies

However, **for current development**, refer to:
- Main documentation: `README.md`, `NEWS.md`
- User guides: `vignettes/`
- Code examples: `examples/`
- Function documentation: Generated from R source via roxygen2

## Running Examples

For instructions on conditional example execution, see `scratch/RUNNING_EXAMPLES.md`.
